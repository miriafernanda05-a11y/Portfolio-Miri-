PORTFÓLIO - MIRIÃ FERNANDA

Abra o arquivo index.html no navegador (duplo clique).

Arquivos que você deve colocar nas pastas (com estes nomes):
  imagens/perfil.jpg        foto de perfil (hero)
  imagens/imagem.jpg        imagem em destaque
  imagens/infografico.png   infográfico
  video/video.mp4           vídeo
  audio/audio.mp3           áudio
  animacao/animacao.mp4     animação
  musica/musica.mp3         música

Para trocar textos, cores e links das redes, edite o index.html
(procure os comentários em maiúsculas e a seção :root no CSS).
